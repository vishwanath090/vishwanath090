## Selected Projects

### 🔧 Multithreaded HTTP Proxy Server &nbsp;—&nbsp; Java

Built a fully functional HTTP proxy server from the ground up — no frameworks, no shortcuts. The server manages a custom thread pool, handles concurrent socket connections, and routes HTTP requests through a pipeline designed for throughput and safety under load.

This project was an exercise in systems programming and Java concurrency internals: understanding how `ExecutorService` actually works, where thread contention emerges, and how to design for correctness before optimizing for speed. The kind of work that separates engineers who use concurrency from those who understand it.

**Core concepts:** Thread pooling · Socket programming · HTTP parsing · Java concurrency internals

[→ View Repository](https://github.com/vishwanath090/multithreaded-http-proxy-server)

---

### 💳 Payment Wallet + Real-Time Chat Backend &nbsp;—&nbsp; Python

A production-modelled backend for a digital payment wallet with integrated real-time messaging. The architecture separates concerns cleanly: a REST layer for account management and transactions, a WebSocket layer for live chat, and JWT-based auth guarding both.

The interesting design challenge was keeping the wallet's transactional integrity — atomic balance updates, idempotent operations — decoupled from the async, stateful nature of the chat system. Two domains with fundamentally different consistency requirements, living in the same backend.

**Core concepts:** Async architecture · WebSockets · Financial domain design · REST API design · JWT auth

[→ View Repository](https://github.com/vishwanath090/payment-wallet-chat-backend)

---

### 🤖 AI Story Generator &nbsp;—&nbsp; Python, LLM APIs

A generative writing engine built around language model APIs and structured prompt engineering. The focus was on the engineering layer around the model — managing context windows, structuring API calls for coherent multi-turn outputs, and handling the failure modes that come with non-deterministic generation.

This is the kind of applied AI work that matters in production: not fine-tuning a model, but knowing how to build reliably *around* one.

**Core concepts:** LLM API integration · Prompt engineering · Context management · NLP pipeline design

[→ View Repository](https://github.com/vishwanath090/Ai_Story_Generator-)

### 🔐 Decentralised Identity Verification &nbsp;—&nbsp; JavaScript

A blockchain-inspired identity management system built on cryptographic primitives. Implements decentralised trust models and digital signature verification — exploring how Web3 authentication concepts can be applied to backend systems without requiring a full blockchain stack.
